# Architecture Overview The architecture of Persistent Mind is designed to provide a scalable, fault-tolerant, and high-performance memory system. ## Components 1. Client: The client is responsible for sending requests to the load balancer. 2. Load Balancer: The load balancer routes incoming requests to the memory nodes. 3. Memory Node: The memory node is responsible for storing and retrieving memory. 4. Memory Store: The memory store is a combination of in-memory and disk storage.
